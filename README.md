# ZAQELORA Corporate Website

A responsive, static corporate website for the ZAQELORA healthcare technology venture.

## Files

- `index.html` — website structure and content
- `assets/css/style.css` — responsive visual design
- `assets/js/main.js` — mobile navigation and dynamic footer year
- `assets/images/` — SVG brand marks and favicon

## Preview

Open `index.html` in a modern browser. The site is static and does not require a build step or backend.

## Publish with GitHub Pages

1. Create a GitHub repository for the ZAQELORA website.
2. Upload the contents of this folder to the repository root (not the containing folder itself).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site and use the generated URL.

## Before public launch

- Confirm legal clearance for the ZAQELORA name, logo and product names.
- Replace the contact section with verified business contact details when available.
- Add final privacy, terms and accessibility information before collecting user data.
- Do not connect patient or clinic data to this static corporate site.

## Notes

This site describes ZAQELORA and its product concepts as being in development. It does not claim that the planned products are currently operational or clinically validated. No enquiry form is included because no verified contact endpoint or backend has been configured.
